# pharma-observatory

This gem is an alias. The canonical gem is [`pharmaobservatory`](https://rubygems.org/gems/pharmaobservatory),
the Ruby client for the [Pharma Observatory](https://pharmaobservatory.com) public REST API
([API reference](https://pharmaobservatory.com/api-reference)).

Installing `pharma-observatory` installs `pharmaobservatory` at the same version, and
`require "pharma-observatory"` loads it. Prefer the canonical name:

```shell
gem install pharmaobservatory
```

```ruby
require "pharmaobservatory"
```
